# Demo Recording Checklist

## Before Recording
- [ ] Start the local dashboard (`python -m streamlit run app.py`).
- [ ] Verify the application loads correctly at `http://localhost:8501`.
- [ ] Verify all figures and charts render without errors.
- [ ] Close all unrelated browser tabs, applications, and windows.
- [ ] Hide any visible filesystem paths, terminal histories, or private information.
- [ ] Verify microphone levels and ensure a quiet environment.

## During Recording
- [ ] Keep a steady, conversational pace; avoid rushing or sounding like you are reading an academic paper.
- [ ] Show the interactive Streamlit dashboard early (around the 2:20 mark).
- [ ] Explicitly emphasize the Budget-Network Paradox as the core insight.
- [ ] Avoid excessive listing of technologies; focus on the scientific question and the engineering methodology.
- [ ] Only click controls explicitly listed in the `Live Dashboard Sequence Instructions` to ensure smooth rendering.

## After Recording
- [ ] Verify the total video duration is strictly under 5:00 minutes.
- [ ] Review audio playback for clarity, background noise, and syncing.
- [ ] Verify no private information, API keys, or unrelated code leaked onto the screen.
- [ ] Verify that no causal forecasting claims or exaggerated LLM intelligence claims were accidentally spoken.
